A program that writes the one sentence a house cat would say in its own defence, five seconds after sweeping a glass off the table. No apology, no confession — just the cat's case for itself:

> It sat in my sunbeam, judging me with its smug little reflection, so I evicted it.

## Run it

```sh
node main.ts
```

`main.ts` writes the sentence to `/output/entry.txt` (82 characters, one sentence).
